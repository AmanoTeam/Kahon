Features

- Ignore extension-specific rate limits
- Boost the maximum number of concurrent downloads
- Trust all extensions by default
- Disable caching for library updates
- Allow editing manga metadata
- Allow saving manga search terms and filters
- Allow silently uninstalling extensions using Shizuku (upstream only supports silent installation)
- Show up to 3 items in the "Last used" tab instead of just one
- Pinch-to-zoom support for manga covers
- Reader autoscroll
- Auto-hide app bars on scroll

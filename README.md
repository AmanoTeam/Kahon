# Kahon

A fork of Mihon, a free and open-source manga reader for Android.

## Features

- Ignore extension-specific rate limits for faster browsing, page loading, and downloads.
- Increase the maximum number of concurrent downloads.
- Trust all extensions by default.
- Disable caching during library updates.
- Allow editing manga metadata.
- Remove proprietary Google components (Firebase and Crashlytics) to improve privacy.

## Enhancements

- Add a Shizuku-based uninstall service.
- Show up to 3 items in the **Last used** tab instead of only one.

## Releases

You can download Kahon releases from either [GitHub](https://github.com/AmanoTeam/Kahon/releases) or [F-Droid](https://f-droid.org/packages/com.amanoteam.kahon).
